# Fuentes extraídas del artefacto ejecutable

Estos archivos corresponden al HTML autónomo incluido en este repositorio:

- `engine.js`: contiene el motor base y sus reglas docentes extendidas.
- `references.js`: textos de referencia para diversos escenarios.
- `app.js`: interfaz, gestor de casos, mapa causal y gráficos.
- `styles.css`: estilos visuales.

**Importante:** la aplicación se distribuye ya empaquetada como `../index.html`. Estos archivos no son dependencias dinámicas del HTML; su propósito es permitir inspección técnica, revisión y futuras refactorizaciones. El notebook generador permanece como fuente de generación autónoma. No edites estos archivos suponiendo que `index.html` cambiará por sí solo.
