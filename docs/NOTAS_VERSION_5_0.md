# Macro Studio 5.0 — Primer lanzamiento público

**Macro Studio** es un simulador interactivo y cualitativo de macroeconomía, desarrollado en español por **Juan Ignacio Garbanzo Fallas**.

## Incluye

- Cuatro mercados interrelacionados: bienes y servicios, laboral, monetario y cambiario.
- Diagrama de causalidad con secuencias y efectos de primer y segundo orden.
- Representación conjunta del modelo **IS–LM–BP**.
- Selección de rutas de transmisión y de canales predominantes cuando los efectos se contraponen.
- Biblioteca editable de escenarios, modo exposición y exportación/importación JSON.
- Aplicación HTML autónoma y notebook Jupyter autocontenido para regenerarla.

## Archivos de esta versión

- `Macro_Studio_5_0.html`: aplicación lista para abrir en el navegador.
- `Macro_Studio_5_0_Final_Notebook_Generador.ipynb`: código generador y reproducible.

## Alcance metodológico

Se trata de un **modelo docente cualitativo**, no de una estimación cuantitativa, proyección empírica ni aval institucional. La interpretación depende de las hipótesis seleccionadas. El repositorio incluye pruebas de regresión automatizadas y un registro de 255 configuraciones históricas y 22 comprobaciones funcionales del paquete de origen; estos recuentos no deben interpretarse como una certificación de todos los escenarios macroeconómicos posibles.
